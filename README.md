### Requirements
- Vulkan SDK saved as environment variable $VULKAN_SDK
- RayTracer uses C++23
- GoogleTest is cloned automatically when building

### Getting Started
Build with `cmake -B build -DCMAKE_BUILD_TYPE=Release -G Ninja`
